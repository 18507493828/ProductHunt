01 / 产品概述
01

产品概述

码上创是 CSDN 出品的社区驱动应用共创平台。用户可借助华为码道、WorkBuddy、Trae Work、千问 Work 等 AI 构建工具， 围绕校园、社交、公益、健身、户外等真实场景快速做出可体验的 Web 应用，发布到应用广场，并通过多渠道分享冲榜，赢取现金激励。

产品定位

构建者

降低「做什么、用什么做、怎么上线」的门槛，提供场景话题、工具引导与部署路径，帮助快速完成从创意到上架。

体验者

在应用广场按场景浏览与体验作品，点赞互动，发现社区里正在发生的新应用。

活动方

通过周榜、月榜、季榜与工具赞助激励，拉动构建、发布与推广，形成可持续的共创活动机制。

运营方

后台可配置场景话题、构建工具、榜单奖金、推广渠道与审核流程，支撑日常活动运营。

核心价值

  • 完整闭环选题构建 → 提交审核 → 广场曝光 → 分享回流 → 榜单激励，一站完成。
  • 场景化选题预置生活与校园等真实话题，减少从零构思的成本。
  • 工具生态开放支持多家 AI 构建工具接入；选用华为码道并成功发布，可领取活动激励。
  • 可运营热度浏览、点赞、分享回流共同影响热度，周 / 月 / 季榜持续激励。
  • 社区背书依托 CSDN 开发者社区，连接创作、展示与传播。

02–03 / 旅程 · 功能
02

用户旅程

平台主路径围绕「我要构建 / 我要发布 / 我要霸榜」三条主线展开，贯穿发现、构建、上线与传播。

01
发现浏览广场与激励
02
构建场景 · 话题 · 工具
03
部署本地构建 · 云上线
04
发布提交审核上架
05
霸榜分享冲榜领奖
PATH 01

我要构建

构建向导按五步引导：选择场景 → 选择话题 → 选择构建工具 → 本地打开工具完成构建 → 前往云厂商官网完成部署。系统会生成可复制的任务书，并可保存为待发布草稿。

PATH 02

我要发布

填写应用名称、一句话介绍、体验链接、分类与话题、封面等信息后提交审核。审核通过即进入应用广场，支持标注 H5、PC、小程序、App 等形态。

PATH 03

我要霸榜

一键分享至小红书、抖音、微信朋友圈、CSDN 博客等渠道，带动浏览与回流热度。周期内热度靠前的作品进入周榜、月榜、季榜，按名次获得对应激励。

03

核心功能

模块能力说明
门户首页展示品牌主张、本期激励、平台数据概览，以及构建 / 发布 / 霸榜入口与热门应用速览。
应用广场浏览已上架应用，支持按场景筛选、按最热 / 最新 / 点赞排序；侧栏同步展示码上创榜单。
构建向导场景、话题、工具、本地构建、云部署五步流程；生成任务书，支持草稿保存与继续编辑。
构建工具可配置接入华为码道、WorkBuddy、Trae Work、千问 Work 等；赞助工具可设置发布成功后的现金激励。
产品提交结构化表单提交体验链接与资料；普通用户需审核，通过后进入广场公开展示。
码上创榜单周榜 / 月榜 / 季榜 Top10，结合浏览、点赞、分享回流等热度，并展示对应名次奖金。
分享推广多渠道一键分享文案与链接，拉动站外流量回流，提升应用热度。

SPONSOR PATH

华为码道活动激励

选用华为码道完成构建并成功发布通过审核后，可额外领取活动现金激励（默认每账号限领一次，金额可配置）。

热度与传达

首页展示本期激励说明；热度综合浏览、点赞与分享回流，运营可结合渠道与档位调节节奏。

05

适用场景

01

开发者共创活动

面向社区开发者发起主题构建赛，用场景话题降低参赛门槛，用榜单与现金激励拉动完赛与传播。

02

AI 工具联合运营

将构建工具作为赞助路径接入平台，用户选用指定工具并成功发布即可领取激励，提升工具曝光与转化。

03

校园与垂直场景共创

围绕校园、社交、公益、健身、户外等场景持续产出可体验应用，形成可浏览、可互动的作品库。

04

内容与流量联动

结合小红书、抖音、朋友圈、CSDN 博客等渠道分享，把站外内容流量回流到应用体验与榜单竞争。

运营可配置项

  • 构建场景、话题与工具目录
  • 周 / 月 / 季榜奖金与码道激励
  • 首页激励文案
  • 推广渠道与分享文案
  • 活动、分类、轮播与导航
  • 应用审核与发奖流程
